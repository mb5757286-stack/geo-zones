# geo-zones

Приложение для Redmi Watch 5 (Vela quick app): предупреждение, когда GPS попадает в запрещённую зону.

- `zone-editor.html` — редактор зон на карте. Рисуйте полигон или круг, нажмите «Готово» и скопируйте текст в `zones.js`.
- `zones.js` — список зон.
- `pages/index/` — экран и логика проверки.
- `manifest.json` — права на геолокацию и вибрацию.

Код не проверялся на реальных часах: API Vela (`@system.geolocation`, поля ответа) нужно сверить с документацией.
