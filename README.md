# geo-zones

«Геозона» — приложение для Redmi Watch 5 (Vela quick app). Следит по GPS и предупреждает вибрацией,
когда вы близко к запретной зоне (до 120 м) или внутри неё.

- `editor/index.html` — отдельный редактор зон на карте (круг или полигон). Результат сохраняется в `src/common/zones.js`.
- `src/` — само приложение; `src/common/geo.js` — геометрия зон.
- `dist/*.rpk` — готовая сборка (обновляется воркфлоу `build-rpk` после каждого пуша).

Формат зон: `{ name, type: 'circle', c: [lat, lon], r: метры }` или `{ name, type: 'poly', pts: [[lat, lon], ...] }`.
